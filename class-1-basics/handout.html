الفكرة الكبيرة The big idea

الأتمتة = أن تشرح الخطوات مرة واحدة، فيكرّرها الحاسوب عنك كل مرة. كل أتمتة لها 3 أجزاء فقط: المُشغِّل Trigger (متى نبدأ؟) ← الخطوات Steps (ماذا نفعل؟) ← النتيجة Result (ماذا نحصل؟).

📜 سير العمل Workflow

⏰ المُشغِّل Trigger

كيف تتحدث التطبيقات؟ HTTP in the restaurant

تطلب (Request) من النادل (API)، فيرجع لك المطبخ (Server) بالرد (Response) ومعه رقم صغير يخبرك ماذا حدث.

Methodفي المطعم · مثال
GET«أرني» · كم الحرارة اليوم؟
POST«خذ طلبي» · إرسال نموذج
PUT / PATCH«غيّر طلبي» · تعديل رقم هاتف
DELETE«ألغِ طلبي» · حذف موعد
Codeرد المطعم · المعنى
200«تفضّل طلبك» ✅ · نجاح
404«ليس في القائمة» · العنوان خطأ
401 / 403«للأعضاء فقط» 🔒 · لا بطاقة
500«مشكلة في المطبخ» 🔥 · الخطأ عندهم

🧠 قاعدة سهلة: 2xx نجاح · 4xx مشكلة في طلبك · 5xx مشكلة عند الخادم. والـ Headers = ملاحظات صغيرة على ورقة الطلب (مثل بطاقة العضوية).

قراءة الـ JSON Reading JSON

  1. الأقواس { } تجمع الاستمارة كاملة.
  2. كل سطر: مفتاح ثم : ثم قيمة.
  3. النص بين علامتي تنصيص "Amman"، والرقم بدونها 21.7.
  4. القائمة بين أقواس مربعة [ ].
  5. قد تجد استمارة داخل استمارة، مثل current.

🔎 في المثال: الحرارة في المفتاح temperature_2m داخل current، ووحدتها في current_units.

{
  "latitude": 31.973888,
  "timezone": "GMT",
  "current_units": {
    "temperature_2m": "°C",
    "wind_speed_10m": "km/h"
  },
  "current": {
    "time": "2026-10-31T14:15",
    "temperature_2m": 21.7,
    "wind_speed_10m": 4.3
  }
}

🦊 لعرض الـ JSON بشكل مرتب: استخدم Firefox (يرتّبه تلقائياً)، أو في Chrome فعّل خانة Pretty print أعلى الصفحة.

الجرس أم التفقّد؟ Webhook vs Polling

🔔 جرس الباب Webhook

التطبيق الآخر يخبرك فوراً عندما يحدث شيء، على عنوان خاص (URL) أعطيته له. مثال: وصلت دفعة، نموذج جديد.

🚶 تفقّد الباب Polling

أنت تسأل كل فترة: «هل من جديد؟». أبطأ وفيه طلبات ضائعة، لكنه يعمل مع تطبيقات بلا جرس.

🚫 الأمانلا تشارك أي API key أبداً: لا في واتساب، ولا في لقطة شاشة، ولا في مجموعة الدورة. تسرّب؟ احذفه واصنع جديداً.

Lab 1.3 · اضغط جرس الباب بنفسك Ring a real webhook doorbell

  1. افتح webhook.site (مجاني، بدون حساب). الرابط تحت Your unique URL هو جرس بابك 🔔. انسخه.
  2. الصقه في تبويب ثانٍ، وأضف في آخره ?name= واسمك بالإنجليزية، ثم Enter: https://webhook.site/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx?name=Sara
  3. ارجع إلى التبويب الأول بدون تحديث: ظهرت الرنّة في INBOX. ما الاسم تحت Query strings؟
  4. (اختياري) رنّ من هاتفك أيضاً. كم رنّة في INBOX الآن؟

💡 هذا هو الـ Webhook: التطبيق الآخر يرنّ رابطك لحظة حدوث شيء — وأنت لم تسأل. ⚠️ لا ترسل كلمات سر إلى هذا الرابط.

✅ فحص سريع: جرس أم تفقّد؟ اسأل: من يبدأ الكلام؟ التطبيق الآخر يخبرك بنفسه ← جرس. أنت تسأل كل فترة ← تفقّد.

تذكّر Remember

  • كل أتمتة = Trigger ← خطوات ← نتيجة.
  • الـ API نادل: أطلب منه، وهو يكلّم المطبخ ويرجع بالرد.
  • GET = اقرأ، POST = أرسل. 200 = نجاح، 404 = غير موجود.
  • في الـ JSON: النص بين " "، الرقم بدونها، القائمة بين [ ].
  • Webhook = جرس فوري · Polling = تفقّد كل فترة.
  • لا أشارك أي API key أبداً — ولا في لقطة شاشة.
