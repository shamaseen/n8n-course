ما هو n8n؟ What is n8n?

n8n (يُنطق n-eight-n) لوحة مرئية مثل لوحة LEGO: تضع عليها قطعاً صغيرة اسمها عُقَد (Nodes)، وتوصلها بأسلاك، فتصنع سير عمل (Workflow) يعمل وحده — بدون برمجة. فيه أكثر من 400 تطبيق جاهز. في الدورة نستخدم n8n Cloud من المتصفح (تجربة مجانية بدون بطاقة ائتمان — راجع n8n.io/pricing).

تجربة أم يعمل وحده؟ Execute vs Publish

▶️تجربة الآن Execute workflow

أنت تضغط ← يعمل مرة واحدة وترى النتيجة فوراً. للبناء والتجربة (مثل البروفة).

🚀يعمل وحده Publish

ينتظر المُشغِّل ويعمل في أي وقت. كل تشغيل يُسجَّل في Executions.

خريطة المحرّر Editor map

  1. اسم سير العمل وقائمة ⋯ ← Import ▸ From file
  2. Editor للبناء · Executions سجل كل التشغيلات

التعبيرات Expressions = fill in the blank

نكتب الجملة مرة، و n8n يملأ الفراغ {{ }} من البيانات القادمة:
مرحباً {{ $json.name }} من {{ $json.city }}! ⬅ مرحباً Sara من Amman! 👋

Expressionيعنيمثال
{{ $json.name }}حقل من الـ item القادم الآنSara
{{ $now.format('yyyy-MM-dd') }}تاريخ اليوم2026-10-31
{{ $('City').item.json.city }}قيمة من عقدة سابقة اسمها CityAmman

💡 لا تحفظ! اسحب الحقل من INPUT وأفلته في الإعداد، فيُكتب التعبير لك. ظهر [undefined] بالأحمر؟ اسم الحقل خطأ (name ≠ Name).

مرجع سريع للتمارين Lab 2 quick reference

🧪 2.1 · hello-n8n.json

  1. سير عمل جديد ← ⋯ ← Import ▸ From file (أو انسخ النص والصق Ctrl+V).
  2. Execute workflow ← افتح Build message.
  3. غيّر Sara إلى اسمك في My info وشغّل ثانية.

النتيجة في OUTPUT:

  • message_ar ← مرحباً Sara من Amman! 👋
  • message_en ← Hello Sara from Amman! You like coffee ☕
  • today ← YYYY-MM-DD

🌤️ 2.2 · weather-api.json

  1. استورد ثم Execute workflow.
  2. افتح Get weather ← في OUTPUT: current.temperature_2m
  3. اقرأ الجملة في Weather message.

مثال (الرقم حقيقي ويتغيّر):
🌡️ الطقس الآن في Amman: 21.7°C — الرياح 4.3 km/h

🎯 تحدٍّ: Riyadh (24.71, 46.67) أو Cairo (30.04, 31.24)

🛠️ 2.3 · من الصفر Build from scratch

Trigger manually ← Edit Fields (3 حقول عنك: name · city · hobby) ← Edit Fields ثانية فيها جملة بالسحب ← Execute workflow.
