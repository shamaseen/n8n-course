رسالة «قهوة بوت» الحقيقية (في chat-agent.json ← AI Agent → Options → System Message):

🎭 Roleأنت "قهوة بوت" ☕ — مساعد ودود لمقهى "قفزة" في عمّان.
You are "Qahwa Bot", a friendly assistant for Qafza Café in Amman.
📐 Formatأجب بنفس لغة السائل (عربي أو English). جمل قصيرة وواضحة، مع إيموجي واحد على الأكثر.
📋 Contextنفتح يومياً 8 صباحاً – 11 مساءً. القهوة العربية 1.5 دينار، لاتيه 2.5 دينار، كيك الشوكولاتة 3 دنانير. الموقع: شارع الرينبو.
🧰 Toolsاستخدم أداة Calculator لأي حساب (مثل مجموع طلب أو خصم). استخدم Wikipedia فقط لأسئلة المعرفة العامة.
🚦 Rulesإذا لم تعرف الجواب قل ذلك بصراحة ولا تخترع.

❌ ضعيف: «أنت مساعد. ساعد الزبائن.» ← ردود عامة وأسعار مخترعة. ✅ قوي: الأجزاء الخمسة + «قل لا أعرف».

مفتاح Gemini المجاني Free API key

  1. افتح aistudio.google.com/apikey وادخل بحساب Google.
  2. اضغط Create API key (اقبل الشروط والمشروع الافتراضي إن طُلب منك).
  3. انسخ المفتاح، يبدأ عادةً بـ AIza.
  4. في n8n افتح عقدة Gemini model ← Credential ← Create new credential.
  5. الصق المفتاح في API Key ← Save. يجب أن ترى رسالة نجاح خضراء.
  6. من قائمة Model اختر نموذجاً فيه كلمة «flash».

🔐المفتاح مثل كلمة السر: لا ترسله في مجموعة، ولا تصوّره في لقطة شاشة. إن تسرّب احذفه من نفس الصفحة وأنشئ غيره.

على تيليجرام Telegram bot

  1. في تيليجرام افتح @BotFather (الموثّق ✔️) وأرسل /newbot.
  2. اكتب اسم البوت، ثم اسم مستخدم ينتهي بـ bot مثل qahwa_sara_bot.
  3. انسخ الـ token: مفتاح البوت، وهو سرّي!
  4. استورد telegram-agent.json وأنشئ Credential من نوع Telegram API لعقدتي Telegram Trigger و Reply on Telegram.
  5. اختر مفتاح Gemini في Gemini model، ثم اضغط Publish (في النسخ القديمة: Active).
  6. راسل البوت من هاتفك 📱. كل شخص له دفتر خاص: Session Key = chat.id.

🌐تيليجرام يحتاج رابط HTTPS عاماً: n8n Cloud يعطيك إياه. n8n على جهازك يحتاج أداة tunnel.

تذكّر Remember

  • الوكيل = عقل + دفتر + يدان
  • رسالة النظام: دور، مهمة، سياق، قواعد، شكل
  • المفاتيح والـ token أسرار
  • تيليجرام لا يعمل بدون Publish
  • ردود الذكاء الاصطناعي تختلف كل مرة: اختبر قبل النشر

إذا تعطّل Quick fixes

  • Model not found ← اختر نموذج «flash» آخر
  • 429 / quota ← انتظر دقيقة أو مفتاح آخر
  • البوت صامت ← Publish؟ الـ token؟
  • ينسى ← وصّل Memory بالوكيل
  • يخترع أسعاراً ← شدّد رسالة النظام
